How It Works

1. Embed data: Add a <script type="text/turtle"> tag with your RDF

2. Parse it: $rdf.parse(data, SolidLogic.store, baseURI, 'text/turtle')

3. Render: SolidOS panes automatically display the data

Benefits: No CORS, no server, works offline, instant load
