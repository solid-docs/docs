How it works

      

        
1. Embed: put Turtle in a <script type="text/turtle"> element.

        
2. Parse: $rdf.parse(text, SolidLogic.store, documentUri, 'text/turtle') adds it to the store that every pane reads.

        
3. Draw: panes.getOutliner(document).GotoSubject($rdf.sym(documentUri + '#me'), true, undefined, true, undefined, undefined, { preserveUrl: true }) draws it into #OutlineView.

        
mashlib 3.1 draws into the element with id OutlineView; if there is none, it creates one inside #MainContent, or at the end of <body>. Read the embedding guide.
