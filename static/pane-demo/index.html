What happens

      

        
panes.register(helloPane) adds the pane to the registry after the built-in ones. From then on SolidOS calls its label for every resource it shows, and offers it wherever label returns a string.

        
"Show with the Hello pane" asks for this pane by passing it to GotoSubject: panes.getOutliner(document).GotoSubject(subject, true, helloPane, true, undefined, undefined, { preserveUrl: true }).

        
To load a pane from its own file, export it as the default export of an ES module and import() it. Read Embedding mashlib, and for writing panes the pane guide.
